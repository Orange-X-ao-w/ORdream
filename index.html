一款面向 UTAU 生态的跨平台开源歌声合成工具，主打「零配置上手」，把歌声合成的门槛降到最低。
核心亮点
裸音库直读
无需 oto.ini、character.txt 等配置文件，扫描 WAV 文件即可自动推断音高、辅元边界、重叠参数，拿到同人音库无需学习配置规则，直接开唱。
全平台兼容
基于 C++17 + Qt6 开发，原生支持 Windows / macOS / Linux，无需虚拟机、兼容层，各平台体验一致。
多语言支持
内置中文、英文、日文、韩文、西班牙文界面，适配全球歌声合成爱好者使用习惯。
UTAU 生态兼容
完全复用现有 UTAU 音库资源，已有音库可直接加载，无需二次转换。
开源可扩展
代码完全开源，支持自定义算法扩展，欢迎开发者共同完善音高推断、FRQ 生成等核心模块。
当前进度
目前已实现核心裸音库识别逻辑，支持 WAV 文件头解析、音高自动推断、辅元边界初步标定，控制台版本可正常运行并输出音库参数。GUI 版本正在开发中，后续将陆续上线实时试听、MIDI 导入、WAV 导出、FRQ 自动生成等功能。
适用人群
UTAU 音库创作者：快速验证音库可用性，无需反复调试 oto 配置
歌声合成新手：无需学习复杂的音库配置规则，开箱即用
多平台用户：在 Windows / macOS / Linux 多设备间无缝切换创作
开源爱好者：参与核心算法优化，共建歌声合成工具生态
关于名称
由来：OR 取自 ORANGE（ORAN 奥兰）的前两个字母，dream 代表着音乐的梦想。

含义：ORdream = Open（开放）+ Real（真实）+ Dream（歌声梦想），我们希望打造一款开放、易用、贴近创作者需求的歌声合成工具，让每个人的歌声创作梦想都能轻松落地。
